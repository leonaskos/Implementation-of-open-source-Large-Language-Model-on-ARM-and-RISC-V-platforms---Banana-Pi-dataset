To calculate the derivative of the function f(x) = 3x^2 + 5x - 7 with respect to x, we use the power rule. 

The derivative of x^n with respect to x is n*x^(n-1). 

So, the derivative of 3x^2 with respect to x is:

d(3x^2)/dx = 3 * 2x^(2-1) = 6x

The derivative of 5x with respect to x is:

d(5x)/dx = 5 * x^(1-1) = 5

The derivative of a constant (-7) with respect to x is 0.

Now, we add up the derivatives:

f'(x) = 6x + 5

So, the derivative of the function f(x) = 3x^2 + 5x - 7 is f'(x) = 6x + 5.
